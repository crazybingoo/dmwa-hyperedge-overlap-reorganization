# Code and Data Availability

## Code availability

The MATLAB, Python and R code used for DMWA construction, role–reciprocity metrics, macro-state reconstruction, motif analysis, null models, matching, ablation analyses, joint state-space analysis, simulation-grid stability and Fig. 2–Fig. 7 / Supplementary Fig. 1–Supplementary Fig. 4 rendering is included in this repository.

## Data availability

`Source_Data.xlsx` contains only aggregate numerical values underlying the public figures and Supplementary Table 2. It contains no raw/preprocessed SEEG, row-level human-participant values, participant or seizure labels, clinical linkage data, local paths, Supplementary Table 1 clinical characteristics or Fig. 1 clinical signal source.

Raw SEEG and clinical records remain restricted by participant privacy, ethics approval, consent and clinical data-use conditions. Access, when permissible, requires review through the responsible institution and an appropriate data-use agreement.

## Suggested manuscript wording

The analysis and figure-rendering code and aggregate source data supporting Fig. 2–Fig. 7 and Supplementary Fig. 1–Supplementary Fig. 4 are available at the accompanying GitHub repository. Raw or processed SEEG recordings, row-level derived measurements and clinical records are not publicly available because they contain sensitive human-participant data and are subject to institutional ethics and privacy restrictions.
